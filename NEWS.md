# spinet 0.1.0

* First public version.
* Core object model (`si_interaction`, `si_stack`, `si_metaweb`, `si_field`).
* Spatial interaction engine `si_overlap()` with seven combination rules.
* Forbidden-link module with phenological, morphological, elevational,
  taxonomic and user-defined rules.
* Native, dependency-free implementations of bipartite network metrics with
  degeneracy detection (`si_degenerate()`).
* Interaction beta-diversity partitioning and rewiring diagnostics.
* Coextinction robustness with and without rewiring.
* Simulation engine for factorial virtual experiments.
